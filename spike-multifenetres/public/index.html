Spike — opening a window without a user gesture

WebSocket : disconnected · step 0 — origin hygiene

Each button arms its variant: the opening is then ordered by the server, 15 s later. Touch neither mouse nor keyboard during the countdown (except variant 3, whose click is the tested mechanism, and variant 4, which must be put in the background).

The buttons stay inactive as long as the WebSocket is not connected: without it the server order would arrive nowhere and the measurement would be empty without saying so.

#VariantArmVerdict
1 Normal tab, without activation — control. To be run from an ordinary tab: it refuses to run in the PWA window. —
2 Installed PWA (standalone), without activation. To be run from the window of the installed PWA: it refuses to run in a tab. —
3 Arming on the next click —
4 Notification → clients.openWindow(), window in the background —
